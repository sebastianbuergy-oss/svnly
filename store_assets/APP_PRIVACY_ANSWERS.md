# App Privacy Answers (Draft)

Reconfirm these answers against the final production SDK/network capture before submission.

| Apple category | Collected | Linked to identity | Tracking | Purpose |
|---|---:|---:|---:|---|
| Contact Info: Email Address | Yes | Yes | No | Account management |
| User Content: Photos or Videos | Yes | Yes | No | App functionality, moderation |
| User Content: Other User Content | Yes | Yes | No | Comments/reports/support |
| Identifiers: User ID | Yes | Yes | No | Account, security, analytics |
| Purchases | If Plus enabled | Yes | No | App functionality |
| Usage Data: Product Interaction | Yes | Yes/pseudonymous | No | Analytics, ranking, reliability |
| Diagnostics: Crash/Performance Data | If final tooling enabled | Possibly | No | App functionality |

Not collected: precise/coarse device location, contacts, browsing/search history, health/fitness, financial/payment card details, sensitive info or advertising data. Camera/microphone data is used to create the user’s submitted take. No cross-company tracking is intended and no ATT permission is requested.
